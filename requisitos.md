# Requisitos

Lista de requisitos a serem atendidos em todos os projetos da disciplina.

## Funcionais

- O sistema deve ser uma aplicação cliente-servidor sobre plataforma Web.
- O sistema deve ter aplicação a ser executada no navegador do cliente, o *frontend*, cujo código deve ser descarregado sob demanda.
- O sistema deve ter aplicação na nuvem, o *backend*, para atender às requisições do *frontend*.
- O sistema deve ter documentação de API RESTful para comunicação entre *frontend* e *backend*.
- O sistema deve ter acesso controlado por esquema de autenticação e autorização via provedores externos, como por exemplo Google, Apple e outros.
- O sistema deve possuir persistência de dados de usuários em banco de dados.
- O sistema deve ter documentação de modelagem de dados e de arquitetura do sistema.
- O sistema deve ser capaz de enviar email e notificações para os usuários.
- O sistema deve registrar todas as operações críticas dos usuários no sistema para posterior análise.
- O sistema deve possuir cenários de desenvolvimento e de produção.
- O sistema deve ser implantado em nuvem, em qualquer cenário, com o uso de IaC.
- O sistema deve ser implantado automaticamente em ambiente de produção com o uso de CI/CD.

## Não funcionais

- O sistema deve ter boa responsividade.
- O sistema deve rodar com baixa latência.
- O sistema deve rodar com custo mínimo de operação.
